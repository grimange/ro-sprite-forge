# Antigravity tracked engineering Definition of Done

An in-scope task is ready for QA when task/acceptance criteria are real and verified;
implementation is confined to the bounded slice; supported inputs are version-pinned;
negative and regression tests executed; exact commands/exit codes/hashes documented;
source art, tokens, GRFs and unlicensed extracted code are not committed; and an
independent reviewer has been requested.

A milestone is PASS only if every stated gate was actually demonstrated. M0-S/M0-I/M0-N
are distinct. Environment-blocked M0-N with passing S/I is PARTIAL, not PASS. False
requested/resolved ACT slot or fallback counts as failure. Operator appearance and
composition approval require actual human sign-off. A reviewer only verifies, does not
repair. A successful objective QA review may advance *that scoped task* to Accepted,
subject to actual board permissions, not silently authorize future milestones.
