# RO Sprite Forge — Comprehensive Error & Diagnostic Catalog

This catalog documents all formal `ErrorCode` categories, HTTP API statuses, and key domain diagnostics in **RO Sprite Forge**. Each entry details the originating subsystem, root cause, impact on project state and builds, and the exact next action required by the operator.

---

## 1. Formal Application Error Codes (`ErrorCode`)

These stable error codes are raised as `ForgeError` instances in the Python domain core and mapped to standard HTTP status codes in the workbench API.

---

### `INVALID_ARGUMENT`
- **Originating Subsystem:** Core / CLI / API Request Parsers (`cli.py`, `service/server.py`, `service/workbench.py`)
- **HTTP Status:** `400 Bad Request`
- **Root Cause:** A provided parameter fails validation (e.g. malformed project slug, negative frame ordinal, invalid review scope, out-of-bounds integer).
- **Project State Impact:** No state mutation occurs; the operation is aborted.
- **Operator Next Action:**
  1. Inspect the error message for the specific invalid field.
  2. Ensure project slugs match `^[a-zA-Z0-9_-]{1,64}$` without spaces or path characters.
  3. Ensure frame indices, ordinals, and coordinate values are non-negative integers.

---

### `INPUT_NOT_FOUND`
- **Originating Subsystem:** Storage / Core / Media Ingestion (`core/project.py`, `service/media.py`)
- **HTTP Status:** `404 Not Found`
- **Root Cause:** The requested project ID, resource ID, source blob hash, or file path does not exist on disk.
- **Project State Impact:** No state mutation occurs.
- **Operator Next Action:**
  1. Verify the project exists in your designated `projects/` directory.
  2. If referencing a source image or ACT/SPR resource, check that it was imported into the current project.
  3. Confirm the file path is accessible and not deleted or moved.

---

### `INVALID_INPUT`
- **Originating Subsystem:** Codecs / Media Parsers / Schema Validators (`codecs/act.py`, `codecs/spr.py`, `service/workbench.py`)
- **HTTP Status:** `422 Unprocessable Content`
- **Root Cause:** A file or payload fails structural syntax or format checks (e.g. truncated SPR magic header, invalid ACT action array, corrupt PNG header, schema validation failure).
- **Project State Impact:** Malformed data is rejected immediately; project manifest and blob stores remain clean.
- **Operator Next Action:**
  1. Verify the file format: ACT files must be version 2.4/2.5; SPR files must be version 2.1.
  2. If uploading PNGs, ensure they are valid non-corrupted raster images with 8-bit palette or 24/32-bit RGBA color.
  3. If defining recipes or schemas, inspect JSON syntax against the schema definition.

---

### `INVALID_OUTPUT`
- **Originating Subsystem:** Compiler / Binary Serialization (`compiler/writer.py`, `compiler/engine.py`)
- **HTTP Status:** `500 Internal Server Error`
- **Root Cause:** A compiled output binary failed post-write verification checks (e.g. generated byte counts mismatch expected tables, re-decoding generated ACT yields mismatched slot counts).
- **Project State Impact:** The compiled asset is marked invalid and not promoted to export status.
- **Operator Next Action:**
  1. Review the compilation plan and replacement settings.
  2. Ensure shared SPR isolation policy (`auto`) is enabled if modifying shared sprite images.
  3. Run `ro-sprite-forge verify` on the candidate binary to locate the structural discrepancy.

---

### `IO_ERROR`
- **Originating Subsystem:** Filesystem Layer / Storage (`core/project.py`, `cli.py`)
- **HTTP Status:** `500 Internal Server Error`
- **Root Cause:** An operating system I/O failure occurred (e.g. read-only filesystem, disk full, missing parent directory permissions).
- **Project State Impact:** Transaction is rolled back; temporary staging files are cleaned up.
- **Operator Next Action:**
  1. Verify disk space on the storage volume.
  2. Check write permissions on the `projects/` directory and its subdirectories.
  3. Inspect operating system file locking or antivirus interference.

---

### `CONFLICT`
- **Originating Subsystem:** Concurrency Control / Manifest Persistence (`core/project.py`, `service/server.py`)
- **HTTP Status:** `409 Conflict`
- **Root Cause:** An optimistic locking revision mismatch (`expected_revision != current_revision`), or an attempt to create a project that already exists.
- **Project State Impact:** Stale mutation is rejected; manifest is preserved unchanged.
- **Operator Next Action:**
  1. Refresh the workbench browser tab or reload project state to fetch the latest revision.
  2. Re-apply the desired assignment or review against the updated revision.

---

### `PERMISSION_DENIED`
- **Originating Subsystem:** Security & Access Validation (`service/security.py`, `core/project.py`)
- **HTTP Status:** `403 Forbidden`
- **Root Cause:** An operation was blocked by security policies (e.g. invalid CSRF token, path traversal attempt escaping project root, access to prohibited system directories).
- **Project State Impact:** Request blocked immediately with an audit log event.
- **Operator Next Action:**
  1. If running in a browser, ensure cookies/CSRF tokens are intact (refresh `http://127.0.0.1:8000`).
  2. Verify that all file paths remain within the designated project root.

---

### `PAYLOAD_TOO_LARGE`
- **Originating Subsystem:** HTTP Request Guard / Upload Limits (`service/server.py`, `service/media.py`)
- **HTTP Status:** `413 Content Too Large`
- **Root Cause:** Uploaded file or JSON body exceeds safety thresholds (e.g. file upload > 32 MiB, manifest upload > 16 MiB).
- **Project State Impact:** Request is aborted before buffering into memory.
- **Operator Next Action:**
  1. Compress or crop source assets before uploading.
  2. If importing video, trim candidate clips to bounded segments (< 32 MiB).

---

### `NOT_IMPLEMENTED`
- **Originating Subsystem:** Feature Flags / Deferred Milestone Stubs
- **HTTP Status:** `501 Not Implemented`
- **Root Cause:** The requested feature belongs to a deferred future milestone (e.g. traditional legacy RO client compatibility).
- **Project State Impact:** No state mutation occurs.
- **Operator Next Action:**
  1. Consult the roadmap plan; traditional client compatibility is deferred in favor of pinned Korangar runtime.

---

## 2. Key Domain & Diagnostic Identifiers

---

### `UNDERSPECIFIED_LAYER_TOPOLOGY`
- **Originating Subsystem:** Requirements Resolver (`rsf-8`, `core/requirements.py`)
- **Root Cause:** An actor target was declared without specifying the ordered layer topology (`layers` array is empty or undeclared).
- **Project State Impact:** Blocked. The project cannot evaluate coverage, generate missing work orders, or claim production status.
- **Operator Next Action:**
  1. Open the project in the workbench.
  2. Click **"⚙️ Define Target & Topology"**.
  3. Declare the ordered layers (e.g. `[{"index": 0, "name": "shadow"}, {"index": 1, "name": "body"}]`).
  4. Save the target.

---

### `SOURCE_HASH_MISMATCH`
- **Originating Subsystem:** Content-Addressed Blob Storage & Ledger (`core/project.py`, `ledger/resolver.py`)
- **Root Cause:** An assigned source image on disk does not match its expected SHA-256 hash recorded in the manifest.
- **Project State Impact:** Occurrences referencing this source are flagged `INVALID`. Compilation is blocked.
- **Operator Next Action:**
  1. Re-import the original source file to generate a fresh valid blob.
  2. Update the assignment in the workbench to bind to the new source blob digest.
  3. Perform a visual review on the updated composition.

---

### `UNBOUND_PRODUCTION_COMPOSITION`
- **Originating Subsystem:** Deterministic Compiler (`compiler/engine.py`)
- **Root Cause:** The operator attempted a production export (`production_export` mode), but one or more required layer occurrences are unassigned or lack operator approval.
- **Project State Impact:** Compilation rejected; no binary is published.
- **Operator Next Action:**
  1. Review the Work Order checklist (`coverage` command or bottom bar in workbench).
  2. Ensure all required layers are assigned valid sources.
  3. Complete visual reviews for all frames in the production scope.
  4. Alternatively, use `bounded_replacement` mode to compile only the completed vertical slice.

---

### `VIDEO_SELECTION_NOT_EXACT`
- **Originating Subsystem:** Video Candidate Selection (`service/video.js`, `media/extractor.py`)
- **Root Cause:** Requested PTS or ordinal values do not match any scanned presentation frame in the video container.
- **Project State Impact:** Video candidate staging is rejected.
- **Operator Next Action:**
  1. Click **"Inspect presentation frames"** to rescan the container.
  2. Select exact PTS integers directly from the inspected presentation table.
  3. Ensure candidate counts do not exceed 64 unique frames.

---

### `VIDEO_TOOL_UNAVAILABLE`
- **Originating Subsystem:** Video Adapter (`service/media.py`)
- **Root Cause:** `ffmpeg` or `ffprobe` executable was not found on system `$PATH`.
- **Project State Impact:** Video inspection/extraction features are disabled; all non-video workflows remain fully functional.
- **Operator Next Action:**
  1. Install FFmpeg via system package manager (`sudo apt install ffmpeg` or `brew install ffmpeg`).
  2. Ensure `ffmpeg` and `ffprobe` are executable from the terminal where the workbench was started.

---

### `MISMATCHED_FRAME_COUNT` / `ATTACHMENT_FRAME_MISMATCH`
- **Originating Subsystem:** Attachment Compositor (`compiler/attachment.py`)
- **Root Cause:** An equipment piece, hat, or weapon attachment contains a different frame count than the parent body for the same action/view slot.
- **Project State Impact:** Compositing fails for that action slot; compilation is blocked.
- **Operator Next Action:**
  1. Compare the attachment's frame count against the body resource.
  2. Author or extract matching animation frames so that both resources have identical frame lengths per slot.

---

### `MIGRATION_REQUIRED`
- **Originating Subsystem:** Project Version Classifier (`core/project.py`)
- **Root Cause:** A project created under legacy Schema v1 was opened, but Schema v2 is required to define layer topology.
- **Project State Impact:** Read-only mode until migrated; mutating operations blocked.
- **Operator Next Action:**
  1. Run `migrate_project(projects_dir, project_id, target_version="v2")` via CLI or Python script.
  2. The system creates a `manifest.json.pre-migration.bak` backup and upgrades the manifest to Schema v2.

---

### `UNSUPPORTED_VERSION`
- **Originating Subsystem:** Project Manifest Loader (`core/project.py`)
- **Root Cause:** The manifest declares a schema version that is not recognized (e.g. created by a newer release of RO Sprite Forge).
- **Project State Impact:** Project cannot be opened.
- **Operator Next Action:**
  1. Upgrade your RO Sprite Forge package to the latest release.

---

### `STALE_REVISION_CONFLICT`
- **Originating Subsystem:** Concurrency Guard (`service/workbench.py`)
- **Root Cause:** Two browser tabs or concurrent API requests attempted to modify the project simultaneously.
- **Project State Impact:** The slower operation is rejected to prevent silent overwrites.
- **Operator Next Action:**
  1. Reload the workbench to synchronize with the current revision.
  2. Re-submit the operation.

---

### `UNRECOVERABLE`
- **Originating Subsystem:** Disaster Recovery (`core/project.py`)
- **Root Cause:** The project manifest is corrupted or missing, and no valid `.bak` or `.pre-migration.bak` file exists.
- **Project State Impact:** Project is severely compromised and cannot be automatically restored.
- **Operator Next Action:**
  1. Restore the project from an offline tar/zip archive.
  2. Check the `staging/` directory for any intact staging files.
  3. Recreate the project using original source art in `blobs/` if blobs remain intact.

---

### `PARTIAL_DIAGNOSTIC`
- **Originating Subsystem:** Action Slot Resolver (`core/requirements.py`)
- **Root Cause:** An action or slot requested by the operator does not correspond to a native Korangar client animation slot (e.g. custom offline animation).
- **Project State Impact:** Fully previewable and inspectable in Forge; flagged `[PARTIAL]` to indicate absence of native client playback proof.
- **Operator Next Action:**
  1. If intended for native Korangar gameplay, map the animation to a canonical slot (0..103).
  2. If intended for offline rendering or cinematics, proceed knowing native slot proof does not apply.

---

### `STALE_REVIEW`
- **Originating Subsystem:** Review Invalidation Engine (`core/review.py`)
- **Root Cause:** An approved occurrence's underlying source image, transformation recipe, or layer topology was modified after approval was recorded.
- **Project State Impact:** The approval is invalidated (`status: STALE`). The occurrence must be visually re-reviewed.
- **Operator Next Action:**
  1. Open the workbench and select the flagged occurrence.
  2. Inspect the revised composition in the animation previewer.
  3. Re-approve via **"Operator visual decision"** (`[A] Approve displayed scope`).

---

### `M0_PARTIAL_NATIVE_UNVERIFIED`
- **Originating Subsystem:** Verification Harness (`tests/`)
- **Root Cause:** Structural checks (M0-S) and independent Rust oracle checks (M0-I) passed, but Korangar native playback (M0-N) was not executed due to missing environment dependencies (e.g. headless CI without GPU/display).
- **Project State Impact:** Asset is verified structurally, but native runtime proof remains uncertified.
- **Operator Next Action:**
  1. To achieve full `M0_PASS`, run native verification on a desktop environment with pinned Korangar installed.
  2. Do not represent the build as fully native-verified until Gate M0-N is executed and recorded.

---

### `ANCHOR_MISSING`
- **Originating Subsystem:** Attachment Compositor (`compiler/compositor.py`)
- **Root Cause:** An ACT frame for a multi-part actor (e.g. head + body) is missing Attach Point 0 (head anchor) coordinates.
- **Project State Impact:** The head sprite defaults to origin `(0, 0)`, causing visible detachment or misplacement.
- **Operator Next Action:**
  1. Edit the body ACT file to restore valid attach point 0 coordinates.
  2. Verify correct anchor positioning in the workbench animation inspector.
